# core_integrity

Правила:
- Модули ядра `rsgi_wsrpc/core/` по умолчанию НЕ ЗАТРАГИВАЮТСЯ без веской причины.
- Внесение изменений допускается ТОЛЬКО когда это крайне необходимо — для устранения ошибки/бага или для критического улучшения производительности/архитектуры.
- При этом ОБЯЗАТЕЛЬНО соблюдается строгий регламент:
  1. **ВСЕГДА сначала спросить пользователя** и получить его явное подтверждение перед внесением любых правок в `rsgi_wsrpc/core/`.
  2. Все внесенные изменения **ОБЯЗАТЕЛЬНО записать в файл `rsgi_wsrpc/core/changed.md`** с подробным описанием того, что именно сделано, почему и к каким последствиям это приводит.
