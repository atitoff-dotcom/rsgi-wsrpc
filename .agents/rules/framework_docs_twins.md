# framework_docs_twins

Правила:
- Вся документация фреймворка `rsgi-wsrpc` ведется строго в двух параллельных папках-близнецах:
  1. `docs/` — основная документация фреймворка на **английском языке**.
  2. `docs_ru/` — зеркальная документация фреймворка на **русском языке**.
- Структура файлов и разделов в `docs/` и `docs_ru/` абсолютно идентична («близнецы»):
  - Каждому документу `docs/<path>/<name>.md` строго соответствует `docs_ru/<path>/<name>.md`.
  - Любые изменения, дополнения и новые главы обязательно синхронно вносятся в обе папки.
